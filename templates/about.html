About the Project

Border Crossing Wait Time Predictor

This project aims to predict wait times at the Blaine Peace Arch border crossing between Vancouver and Seattle using machine learning techniques. By analyzing historical patterns and incorporating current conditions, we provide accurate predictions to help travelers plan their border crossings more efficiently.

The Model

We use Facebook's Prophet forecasting library, which is designed for time series data with strong seasonal patterns. Our model incorporates:

  • Daily patterns (rush hours vs. off-peak times)
  • Weekly patterns (weekday vs. weekend differences)
  • Monthly and yearly seasonality
  • Holiday effects for both US and Canadian holidays
  • Current wait time information (when available)
Data Sources

Our model is trained on historical border crossing wait time data, which includes:

  • Historical average wait times by month, day, and time
  • Current border wait time information
  • US and Canadian holiday calendars
How to Use

To get a prediction:

  1. Go to the Home page
  2. Select your target date and time
  3. Optionally, enter the current wait time if available
  4. Click "Predict Wait Time" to see the results
Visualizations

Visit the Visualize page to explore historical patterns in border crossing wait times, including hourly, daily, and monthly trends.

Technical Details

Technologies Used
  • Prophet: Facebook's time series forecasting library
  • Python: Core programming language
  • Pandas: Data manipulation and analysis
  • Flask: Web application framework
  • Plotly: Interactive data visualizations
  • Bootstrap: Frontend styling and components
Model Performance

Our model achieves high accuracy in predicting border crossing wait times, with performance metrics including:

  • Mean Absolute Error (MAE): Measures the average magnitude of errors
  • Mean Absolute Percentage Error (MAPE): Expresses accuracy as a percentage
  • Root Mean Squared Error (RMSE): Gives higher weight to larger errors
Future Improvements

We're continuously working to improve the model's accuracy and features:

  • Incorporating weather data
  • Adding special event information
  • Implementing real-time updates
  • Expanding to additional border crossings
  • Developing a mobile application
